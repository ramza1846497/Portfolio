# 夜の学校 — 第一話「トイレの花子さん」

夜の校舎を舞台にした、3D 一人称の探索ホラー（プロトタイプ）。
都市伝説・怪異を調べて「決まり」を解き明かし、脱出する。

- Three.js + Vite + TypeScript（ブラウザで動作・スマホ対応）
- 3D モデルは Box / Plane と canvas で描いたテクスチャだけで構成
- 効果音は Web Audio API でその場で合成（音声ファイルなし）

## 動かし方

```sh
cd night-school
npm install
npm run dev        # http://localhost:5173/
```

### スマホで確認する

`npm run dev` は `--host` 付きで起動するので、同じ Wi-Fi のスマホから
ターミナルに表示される `Network: http://<PCのIP>:5173/` を開けば遊べる。
Tailscale を使っている場合は、PC の Tailscale の IP（`100.x.y.z`）でも開ける。

本番ビルドは `npm run build` で `dist/` に出力される（相対パスなので、
nginx などの静的ファイル置き場にそのまま置ける）。

URL に `?debug` を付けると、FPS・座標・描画回数を左下に表示する。

## ゲームの流れ（第一話）

舞台は校舎の 2 階と 1 階。七不思議のうち四つの怪異が、それぞれの「決まり」を持っている。

| 怪異 | 場所 | 決まり | 手がかり | 得る物 |
|---|---|---|---|---|
| 十三階段 | 西階段 | 夜だけ現れる十三段目を踏むと 2 階に戻される。またいで降りる | 階段前の壁の落書き | 1 階へ行ける |
| 動く人体模型 | 1 階・理科室 | 理科室に入ると動き出す。見ている間は動かない。背を向けると近づいてきて、捕まると体力が減る。心臓を返すと止まる | 理科室のきまり・宿直日誌・落とし物箱 | 音楽室の鍵 |
| 音楽室のピアノ | 2 階・音楽室 | ひとりでに「かえるのうた」を途中まで弾いて止まる。続きを鍵盤で弾く | 黒板の今月の歌・宿直日誌 | 女子トイレの鍵 |
| トイレの花子さん | 2 階・女子トイレ | 入口から三番目の個室を三回ノックし「はなこさん、いらっしゃいますか」。初めて入ると個室の扉がいっせいに暴れ、明かりが激しく明滅する。正しい個室は三回目のノックで叩き返してくる | 2-A のメモ・2-B の黒板・掃除当番表 | 昇降口の鍵 |
| 保健室で眠る子（寄り道） | 1 階・保健室 | ベッドで眠っている人を起こしてはいけない。起こそうとすると放り出される | 床の紙切れ（理科室のきまり 四）・保健室の貼り紙 | 真のエンディング |

保健室の鍵は、職員室の「保健」の机の引き出し（四桁のダイヤル錠）にある。
番号は宿直日誌の「あの子が来なくなった日」で、2-B の出席簿と 2-A の黒板から分かる。

1. 2 階で目を覚ます。東階段は机で塞がれていて、下りられるのは西階段だけ
2. 十三階段を抜けて 1 階へ。理科室に入ると人体模型が動き出す。職員室の落とし物箱で心臓を見つける
3. 人体模型から目を離さずに近づき、心臓を返す → 音楽室の鍵
4. 2 階の音楽室でピアノの続きを弾く → 女子トイレの鍵
5. 女子トイレで花子さんを呼ぶ → 昇降口の鍵
6. 1 階の昇降口から外へ。……校門の外には、細い道も民家もない。霧の中の一本道を進む
7. しばらく歩くと、コンビニ「ヨミマート」の明かりが点く（下の「学校の外」）
8. 会計を済ませて店を出るとエンディング。クリア画面に調査時間と記録数が出る
   - 保健室で眠る人を起こさずに離れていれば、真のエンディング「目覚め」。そうでなければ「帰宅」

## 学校の外：真夜中のコンビニ

| 怪異 | 決まり | 手がかり |
|---|---|---|
| 真夜中のコンビニ（店員はのっぺらぼう） | お会計が済むまで店から出られない。店員の顔を見てはいけない（4.5m 以内で顔が画面に映っている間、近いほど速く体力がじわじわ減る） | 入口の貼り紙「深夜のお客様へ」 |

- 夜道に古い十円玉が三枚落ちている（チカッ、チカッと光るので、霧の向こうからでも見つけられる）。それがお代になる（足りないまま入っても、レジか自動ドアで店員が外へ出してくれる。拾って戻れば会計できる）
- レジはカウンターの東の端、店員は西の端。レジの前で正面を向けば、店員の顔は視界に入らない
- 駐車場に落ちている「おつかいメモ」（差出人は花子）にある三品——菊の花・線香・まんじゅう——をカゴに入れ、
  下を向いたままレジで会計する。違う物を入れると叱られて体力 -10、カゴが空になる
- 店の新聞と、会計後のレシートが、花子さんの話と七不思議の六つ目につながる

## 体力ゲージと怪異メーター

画面左上に「体力」と「怪異」のメーターがある。

- **怪異メーター**：怪異の気配に近づくほど針が振れ、空電のようなノイズが鳴る。
  赤い帯まで振り切れたら危険。気配はステージデータの `presences` と、actor の `threat()` から決まる
- **体力**：怪異に捕まったり、決まりを破ったりすると減る
  - 人体模型に捕まる：-35 ／ 花子さん・十三階段・ピアノで間違える：-10 ／ 眠る人を起こそうとする：-15
  - 回復：職員室の救急箱（+40）、保健室の救急箱（全回復）。どちらも一度きり
  - 0 になると気絶して、その階の階段で目を覚ます（体力 50、進み具合はそのまま）。気絶の回数はクリア画面に出る
- **人体模型**：理科室に入った時点で動き出す。画面に映っている間は止まり、背を向けたり壁の陰に入ったりすると近づいてくる。
  心臓を返すと、もう追ってこない

## ファイル構成

```
src/
  main.ts              タイトル画面と起動
  game/
    types.ts           ステージ定義の型（条件・アクション・トリガー・actor）
    state.ts           状態（フラグ・変数・所持品・手帳）を一か所で管理
    runner.ts          データで書いたアクション列を順に実行する
    validate.ts        ステージデータの参照切れチェック（開発時のみ）
    game.ts            ゲームループ・照準（レイキャスト）・トリガー・UI の取りまとめ
  engine/              入力・プレイヤー・当たり判定・照明・効果音・テクスチャ
  world/               Box/Plane を並べる WorldBuilder と材質
  ui/                  HUD・会話（タイプライター）・手帳・鍵盤入力
  stages/
    index.ts           ステージ一覧
    episode1/
      index.ts         第一話の定義（下の部品をまとめる）
      floor2.ts        2 階のマップ          floor1.ts   1 階のマップ（＋人体模型の経路）
      parts.ts         マップ部品（窓・机・階段・扉・幽霊・人体模型・ピアノなど）
      model.ts         人体模型の動き（actor）
      outside.ts       学校の外のマップ（夜道・コンビニ）
      clerk.ts         コンビニの店員の「顔を見るな」（actor）
      data/
        common.ts      導入・脱出・掲示板・職員室の手がかり・目的表示
        stairs.ts      十三階段          model.ts    動く人体模型
        piano.ts       音楽室のピアノ    hanako.ts   トイレの花子さん
        nurse.ts       保健室で眠る子（寄り道・真のエンディング）
        outside.ts     学校の外：夜道とコンビニ・エンディング
```

## 怪異（ステージ）の追加方法

1. マップに物を置く（`builder.wallX / wallZ / box / plane` で形を作り、
   調べられる物は `builder.interactable('id', mesh)` か `builder.hitbox('id', min, max)` で登録。
   階の移動先は `builder.spawn('名前', x, z, 向き)`）
2. `data/<怪異>.ts` に `StagePart`（`interactables`・`notes`・`items`・`scripts`・`triggers`・`visibility`）を書き、
   `episode1/index.ts` の `mergeParts([...])` に足す
   - 反応は `reactions` の上から順に `when` を見て、最初に当てはまったものを実行
   - アクション例：`{ say: [...] }` `{ note: 'id' }` `{ flag: 'x' }` `{ addVar: 'n', value: 1 }`
     `{ choice: { options: [...] } }` `{ if: 条件, then: [...], else: [...] }` `{ run: 'スクリプト名' }`
     `{ fx: 'blackout' | 'strobe' | ... }` `{ sfx: 'knock' }` `{ open: '扉' }` `{ teleport: '地点' }`
     `{ rattle: ['扉', …] }` `{ fx: 'strobe', target: '明かりの名前' }` `{ damage: 10 }` `{ meter: 1 }` `{ look: '物' }` `{ melody: 'ド レ ミ' }` `{ sequence: { keys, answer, correct, wrong } }` `{ clear: true }`
   - `triggers` はプレイヤーが範囲に入ったときに実行、`visibility` は条件で物を出し入れする
   - 会話文の `{変数名}` は、その時点の値に置き換わる（例：`コン……（{knockCount}回）`）
3. 追いかけてくるなど、データで書きにくい動きは `Actor` としてコードで書き、`actors` に登録する（例：`episode1/model.ts`）
4. 新しい話（別の夜）にするなら、`src/stages/index.ts` に `StageDef` を足す

`npm run dev` 中は、存在しない手帳 ID・スクリプト名・扉名・地点名などをコンソールにエラーとして出す。
