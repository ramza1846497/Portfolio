# 夜の学校 — 第一話「トイレの花子さん」

夜の校舎を舞台にした、3D 一人称の探索ホラー（プロトタイプ）。
都市伝説・怪異を調べて「決まり」を解き明かし、脱出する。

- Three.js + Vite + TypeScript（ブラウザで動作・スマホ対応）
- 3D モデルは Box / Plane と canvas で描いたテクスチャだけで構成
- 効果音は Web Audio API でその場で合成（音声ファイルなし）

## 動かし方

```sh
cd night-school
npm install
npm run dev        # http://localhost:5173/
```

### スマホで確認する

`npm run dev` は `--host` 付きで起動するので、同じ Wi-Fi のスマホから
ターミナルに表示される `Network: http://<PCのIP>:5173/` を開けば遊べる。
Tailscale を使っている場合は、PC の Tailscale の IP（`100.x.y.z`）でも開ける。

本番ビルドは `npm run build` で `dist/` に出力される（相対パスなので、
nginx などの静的ファイル置き場にそのまま置ける）。

URL に `?debug` を付けると、FPS・座標・描画回数を左下に表示する。

## 操作

| | スマホ | PC |
|---|---|---|
| 移動 | 画面左側をドラッグ（仮想ジョイスティック） | WASD / 矢印キー |
| 視点 | 画面右側をドラッグ | マウスドラッグ |
| 調べる | 右下の「調べる」ボタン | E |
| 手帳 | 右上の「手帳」ボタン | N |

画面中央の照準が、2.5m 以内の調べられる物に向くと名前が出る。

## ゲームの流れ（第一話）

1. 夜の校舎（2 階）で目を覚ます。東端の昇降口は鎖と南京錠で閉ざされている
2. 手がかりを集める（調べると「調査手帳」に記録される）
   - 掲示板：七不思議の貼り紙（花子さんが一つ目）
   - 2-A の教卓のメモ：「はなこさんは入口から三番目の個室にいる」
   - 2-B の黒板：「ノック 3 回のあと『はなこさん、いらっしゃいますか』」
   - ほかにも用具入れ・出席簿・鏡などに小さな手がかりがある
3. 女子トイレの個室を調べて「ノックする」「呼びかける」を選ぶ
   - 3 番目の個室を 3 回ノックしてから呼ぶ → 暗転 →「はあい」→ 扉が開き、鍵が出る
   - それ以外 → 照明が明滅し、笑い声がして、ノック回数がリセットされる
4. 鍵を持って昇降口を調べると脱出。クリア画面に調査時間と記録数が出る

## ファイル構成

```
src/
  main.ts              タイトル画面と起動
  game/
    types.ts           ステージ定義の型（条件・アクション・調べられる物）
    state.ts           状態（フラグ・変数・所持品・手帳）を一か所で管理
    runner.ts          データで書いたアクション列を順に実行する
    validate.ts        ステージデータの参照切れチェック（開発時のみ）
    game.ts            ゲームループ・照準（レイキャスト）・UI の取りまとめ
  engine/              入力・プレイヤー・当たり判定・照明・効果音・テクスチャ
  world/               Box/Plane を並べる WorldBuilder と材質
  ui/                  HUD・会話（タイプライター）・手帳
  stages/
    index.ts           ステージ一覧
    hanako/
      map.ts           3D マップ（第一話の校舎）
      data.ts          調べられる物・会話文・フラグ条件・手帳の文面
      index.ts         ステージ定義
```

## 怪異（ステージ）の追加方法

1. `src/stages/<名前>/` を作り、`map.ts` でマップを組む
   （`builder.wallX / wallZ / box / plane` で形を作り、
   調べられる物は `builder.interactable('id', mesh)` か `builder.hitbox('id', min, max)` で登録）
2. `data.ts` に `interactables`（id・名前・状態ごとの反応）、`notes`、`items`、`scripts` を書く
   - 反応は `reactions` の上から順に `when` を見て、最初に当てはまったものを実行
   - アクション例：`{ say: [...] }` `{ note: 'id' }` `{ flag: 'x' }` `{ addVar: 'n', value: 1 }`
     `{ choice: { options: [...] } }` `{ if: 条件, then: [...], else: [...] }` `{ run: 'スクリプト名' }`
     `{ fx: 'blackout' | 'strobe' | ... }` `{ sfx: 'knock' }` `{ open: '扉' }` `{ clear: true }`
   - 会話文の `{変数名}` は、その時点の値に置き換わる（例：`コン……（{knockCount}回）`）
3. `src/stages/index.ts` に登録する

`npm run dev` 中は、存在しない手帳 ID・スクリプト名・扉名などをコンソールにエラーとして出す。
