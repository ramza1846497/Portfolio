# 夜の学校 — 第一話「トイレの花子さん」

夜の校舎を舞台にした、3D 一人称の探索ホラー（プロトタイプ）。
都市伝説・怪異を調べて「決まり」を解き明かし、脱出する。

- Three.js + Vite + TypeScript（ブラウザで動作・スマホ対応）
- 3D モデルは Box / Plane と canvas で描いたテクスチャだけで構成
- 効果音は Web Audio API でその場で合成（音声ファイルなし）

## 動かし方

```sh
cd night-school
npm install
npm run dev        # http://localhost:5173/
```

### スマホで確認する

`npm run dev` は `--host` 付きで起動するので、同じ Wi-Fi のスマホから
ターミナルに表示される `Network: http://<PCのIP>:5173/` を開けば遊べる。
Tailscale を使っている場合は、PC の Tailscale の IP（`100.x.y.z`）でも開ける。

本番ビルドは `npm run build` で `dist/` に出力される（相対パスなので、
nginx などの静的ファイル置き場にそのまま置ける）。

URL に `?debug` を付けると、FPS・座標・描画回数を左下に表示する。

| | スマホ | PC |
|---|---|---|

画面中央の照準が、2.5m 以内の調べられる物に向くと名前が出る。

## ゲームの流れ（第一話）

舞台は校舎の 2 階と 1 階、渡り廊下の先の中庭と体育館。七不思議のうち四つの怪異が、それぞれの「決まり」を持っている。

| 怪異 | 場所 | 決まり | 手がかり | 得る物 |
|---|---|---|---|---|
| 十三階段 | 西階段 | 夜だけ現れる十三段目を踏むと 2 階に戻される。またいで降りる | 階段前の壁の落書き | 1 階へ行ける |
| 動く人体模型 | 1 階・理科室 | 理科室に入ると動き出す。見ている間は動かない。背を向けると近づいてきて、捕まると体力が減る。心臓を返すと止まる | 理科室のきまり・宿直日誌・落とし物箱 | 体育館の鍵 |
| 走る二宮金次郎像（中ボス） | 1 階・体育館 | 中庭の台座をおりて体育館にいる。突進は横に避け、壁に激突して動けないうちに叩く | 渡り廊下のうわさの貼り紙・空っぽの台座 | 音楽室の鍵 |
| 音楽室のピアノ | 2 階・音楽室 | ひとりでに「かえるのうた」を途中まで弾いて止まる。続きを鍵盤で弾く | 黒板の今月の歌・宿直日誌 | 女子トイレの鍵 |
| トイレの花子さん | 2 階・女子トイレ | 入口から三番目の個室を三回ノックし「はなこさん、いらっしゃいますか」。初めて入ると個室の扉がいっせいに暴れ、明かりが激しく明滅する。正しい個室は三回目のノックで叩き返してくる | 2-A のメモ・2-B の黒板・掃除当番表 | 昇降口の鍵 |
| 保健室で眠る子（寄り道） | 1 階・保健室 | ベッドで眠っている人を起こしてはいけない。起こそうとすると放り出される | 床の紙切れ（理科室のきまり 四）・保健室の貼り紙 | 真のエンディング |

保健室の鍵は、職員室の「保健」の机の引き出し（四桁のダイヤル錠）にある。
番号は宿直日誌の「あの子が来なくなった日」で、2-B の出席簿と 2-A の黒板から分かる。

1. 2 階で目を覚ます。東階段は机で塞がれていて、下りられるのは西階段だけ。2-B の後ろの扉の脇で竹刀を拾い、西階段の前に立ちはだかる影を祓う（最初の戦闘・操作説明）
2. 十三階段を抜けて 1 階へ。理科室に入ると人体模型が動き出す。職員室の落とし物箱で心臓を見つける
3. 人体模型から目を離さずに近づき、心臓を返す → 体育館の鍵
4. 1 階の廊下から渡り廊下へ。中庭の影たちを祓い、体育館で二宮金次郎像を倒す → 音楽室の鍵
5. 2 階の音楽室でピアノの続きを弾く → 女子トイレの鍵
6. 女子トイレで花子さんを呼ぶ → 昇降口の鍵
7. 1 階の昇降口から外へ。……校門の外には、細い道も民家もない。霧の中の一本道を進む
8. しばらく歩くと、コンビニ「ヨミマート」の明かりが点く（下の「学校の外」）
9. 会計を済ませて店を出ると、知らない路地にいる。先へ先へと現れる花子さんについていく（下の「花子さんの家」）
10. 花子さんの家から、自分の家へ。きまりを守って電話に出るとエンディング（下の「自分の家」）

## 学校の外：真夜中のコンビニ

| 怪異 | 決まり | 手がかり |
|---|---|---|
| 真夜中のコンビニ（店員はのっぺらぼう） | お会計が済むまで店から出られない。店員の顔を見てはいけない（4.5m 以内で顔が画面に映っている間、近いほど速く体力がじわじわ減る） | 入口の貼り紙「深夜のお客様へ」 |

- 夜道に古い十円玉が三枚落ちている（チカッ、チカッと光るので、霧の向こうからでも見つけられる）。それがお代になる（足りないまま入っても、レジか自動ドアで店員が外へ出してくれる。拾って戻れば会計できる）
- レジはカウンターの東の端、店員は西の端。レジの前で正面を向けば、店員の顔は視界に入らない
- 駐車場に落ちている「おつかいメモ」（差出人は花子）にある三品——菊の花・線香・まんじゅう——をカゴに入れ、
  下を向いたままレジで会計する。違う物を入れると叱られて体力 -10、カゴが空になる
- 店の新聞と、会計後のレシートが、花子さんの話と七不思議の六つ目につながる

## 花子さんの家

- 表札の名字が削られた古い家。居間の黒電話が鳴り、二月十四日の母親の声が聞こえる
- 子供部屋の連絡帳とカレンダーで、二月十四日（放課後に音楽室でピアノの練習、帰りにトイレへ）が分かる
- 決まり：仏壇へのお供えは「お花 → お線香 → お菓子」の順（仏壇の引き出しの祖母のメモ）。
  線香には台所の引き出しのマッチが要る。順番を間違えると叱られて体力 -10
- 供え終えると花子さんが「ありがとう、おうちにかえってこられた」と言って消え、もう一度黒電話が鳴る。
  「おうちで『ただいま』っていっちゃだめだよ」

## 自分の家

下駄箱の上に、花子さんの「おうちのきまり」がある。

| きまり | 破ると |
|---|---|
| 一、「ただいま」と言わない | 家の奥から何人もの声が「おかえり」と返事をする（体力 -25） |
| 二、「ごはんよ」と呼ばれても台所へ行かない | 流しに向かっていた「母」が振り向く（体力 -25、玄関へ戻される） |
| 三、自分の布団で寝ない | バッドエンド「おかえり」 |
| 四、電話が鳴ったら出る | 家族写真・テレビ・きまりを見たあとに鳴る。出るとエンディング |

- 家族写真は自分の顔だけがぼやけている。テレビの砂嵐に「七、知ってはいけない」が浮かぶ
- エンディング：保健室で眠る人を起こさずに離れていれば「目覚め」（電話は保健の先生）、そうでなければ「帰宅」（電話は本当の母）

## 戦闘

謎解きの合間に、竹刀で戦う場面がある。

- **竹刀**：2 階、2-B の後ろの扉の脇に置き忘れられている。持つと「攻撃」「回避」ボタンが出る
- **登場演出**：初めて出会う敵は、プレイ画面のまま視線がその敵に吸い寄せられ、敵が実際に動いてみせる（予兆 → 攻撃 → 隙）。
  文章では説明しない。演出が終わると、敵はその場所からそのまま戦闘に入る（タップでスキップ可）。中身は `episode1/movies.ts`
  - 影：赤く光って頭に「！」→ 目の前まで飛びかかる → 着地して前のめりに崩れる
  - 二宮金次郎像：床を踏み鳴らして「！」→ 横をかすめて突進 → 壁に激突してぐらつく → こちらを向く。体力が半分を切ると目が燃える
- **予兆の「！」**：敵が攻撃の構えに入ると、頭の上に赤い「！」が出る（戦闘中も同じ）
- **最初の遭遇**：西階段の前の影に近づくと登場演出、主人公の心情がひとこと、そのあと操作説明が出る
- **影（ザコ）**：近づくと赤く光って身構え、飛びかかってくる（-12）。身構えたら回避、着地の隙に叩く。4 回で消える。
  2 階の西階段に 1 体、渡り廊下と中庭に 3 体
- **走る二宮金次郎像（中ボス）**：体育館で待っている。体力ゲージが画面上に出る
  - 遠くからは突進（-25）。突進中は竹刀が弾かれる。横に避ければ壁に激突して、しばらく気絶する（気絶中はダメージ 4 倍）
  - 近くでは踏みつけ（-18）。踏みつけたあとは距離をとって、また突進の構えに入る
  - 体力が半分を切ると目が赤く燃え、動きが速くなる
  - 倒すと音楽室の鍵が手に入り、体力が 30 回復する
- 気絶すると、敵の体力は元に戻る（倒した敵はそのまま）。渡り廊下・体育館で気絶したら渡り廊下の入口で目を覚ます

## 体力ゲージと怪異メーター

画面左上に「体力」と「怪異」のメーターがある。

- **怪異メーター**：怪異の気配に近づくほど針が振れ、空電のようなノイズが鳴る。
  赤い帯まで振り切れたら危険。気配はステージデータの `presences` と、actor の `threat()` から決まる
- **体力**：怪異に捕まったり、決まりを破ったりすると減る
  - 人体模型に捕まる：-35 ／ 花子さん・十三階段・ピアノで間違える：-10 ／ 眠る人を起こそうとする：-15
  - 回復：職員室の救急箱（+40）、保健室の救急箱（全回復）。拾うと持ち物に入り、好きなときに「持ち物」から使える（体力が満タンのときは使わない）。
    使える物があると「持ち物」ボタンに数が出る
  - 0 になると気絶して、その階の階段で目を覚ます（体力 50、進み具合はそのまま）。気絶の回数はクリア画面に出る
- **人体模型**：理科室に入った時点で動き出す。画面に映っている間は止まり、背を向けたり壁の陰に入ったりすると近づいてくる。
  心臓を返すと、もう追ってこない

## グラフィック

- **写真の質感**：壁・床・天井・タイル・塗装した鉄・畳などは、Poly Haven の CC0 テクスチャ（色・凹凸・粗さ）。
  `public/textures` に焼いてあり、読み込めないときは canvas で描いた模様のまま動く
- **3D モデル**：机・椅子・事務机・ベッド・棚・車いす・救急箱などは Poly Haven の CC0 モデル（`public/models`）。
  起動時に読み込み、同じ物はまとめて描く（インスタンシング）。当たり判定は今までの箱のまま。読み込めなかった物は箱で作る
- **人物**：花子さん・影・店員・母親・二宮金次郎像は、丸みのある形（カプセル・回転体・球）をコードで組んだ物
- **光と仕上げ**：懐中電灯の影、隅や接地面の陰（[N8AO](https://github.com/N8python/n8ao) のアンビエントオクルージョン）、
  フィルム調のトーンカーブ、光のにじみ、夜の蛍光灯の色味、周辺減光、フィルムの粒子
- **空気感**：懐中電灯の光の筋と、光の中を漂うほこり（`engine/atmosphere.ts`）
- **建物の作り**：扉・窓のまわりの枠と、床ぎわの幅木は、壁を作るときに自動で付く（`WorldBuilder.trim`）。廊下には天井の梁
- **画質**：タイトル画面で「高・標準・低」を選べる（端末に記憶）。標準は隅の陰を半分の解像度で、低は影・隅の陰・にじみなし、解像度も下げる
- 素材の出典は [CREDITS.md](CREDITS.md)

## 怪異（ステージ）の追加方法

1. マップに物を置く（`builder.wallX / wallZ / box / plane` で形を作り、
   調べられる物は `builder.interactable('id', mesh)` か `builder.hitbox('id', min, max)` で登録。
   階の移動先は `builder.spawn('名前', x, z, 向き)`）
2. `data/<怪異>.ts` に `StagePart`（`interactables`・`notes`・`items`・`scripts`・`triggers`・`visibility`）を書き、
   `episode1/index.ts` の `mergeParts([...])` に足す
   - 反応は `reactions` の上から順に `when` を見て、最初に当てはまったものを実行
   - アクション例：`{ say: [...] }` `{ note: 'id' }` `{ flag: 'x' }` `{ addVar: 'n', value: 1 }`
     `{ choice: { options: [...] } }` `{ if: 条件, then: [...], else: [...] }` `{ run: 'スクリプト名' }`
     `{ fx: 'blackout' | 'strobe' | ... }` `{ sfx: 'knock' }` `{ open: '扉' }` `{ teleport: '地点' }`
     `{ rattle: ['扉', …] }` `{ fx: 'strobe', target: '明かりの名前' }` `{ damage: 10 }` `{ meter: 1 }` `{ look: '物' }` `{ melody: 'ド レ ミ' }` `{ sequence: { keys, answer, correct, wrong } }` `{ clear: true }`
   - `triggers` はプレイヤーが範囲に入ったときに実行、`visibility` は条件で物を出し入れする
   - 会話文の `{変数名}` は、その時点の値に置き換わる（例：`コン……（{knockCount}回）`）
3. 追いかけてくるなど、データで書きにくい動きは `Actor` としてコードで書き、`actors` に登録する（例：`episode1/model.ts`）
4. 新しい話（別の夜）にするなら、`src/stages/index.ts` に `StageDef` を足す

`npm run dev` 中は、存在しない手帳 ID・スクリプト名・扉名・地点名などをコンソールにエラーとして出す。
