# まいにちマート3D（ワンオペ店員シミュレーター）

架空のコンビニ「まいにちマート」で、一人称視点で歩き回りながら品出し・レジ・ホットスナック・掃除・発注をこなすブラウザゲーム（PC向け）。
Three.js 0.170.0 を import map で CDN（jsDelivr）から読み込みます。ビルドは不要です。

## 遊び方

import map とモジュールを使うので、簡易サーバー経由で開きます。

```
cd konbini3d
npx serve .            # または python3 -m http.server
```

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 視点 | マウス（画面をクリックでポインタロック） |
| 調べる・持つ・置く・使う | 左クリック（棚の補充は長押しで連続） |
| 持っている物を下ろす | Q |
| 開店前にすぐ開店 | Enter |
| 一時停止 ／ パネルを閉じる | Esc |

## テスト

```
cd konbini3d
node --test
```

お金の計算・在庫・発注・レジ・フライヤー・掃除の関数に加え、店内の当たり判定（格子状に置いた全地点から歩いて引っかからないか）と、
レジ担当ボットで1日〜3日を通しで回すシミュレーション（客が壁に入らない・止まらない・列の順番が正しい・所持金の増減が利益と一致する）を含みます。

## 構成

- `src/game.js` … ゲーム全体の状態と操作（各 systems をつなぐ。Three.js・DOM 非依存）
- `src/systems/` … 時計・在庫・客・レジ・ホットスナック・掃除・発注・集計（純粋なロジック）
- `src/world/store.js` … 店内レイアウトのデータ（当たり判定の箱・棚の区画・経由点）
- `src/world/collision.js` / `waypoints.js` … AABB の当たり判定と、客の経路（見通しで自動接続した経由点の最短経路）
- `src/world/storeView.js` / `entityView.js` … 見た目。状態を読んでメッシュに反映するだけ（状態 → 見た目の一方向）
- `src/player/` … 一人称移動と、照準の先の物を調べる処理
- `src/ui/` … HUD・レジ・発注・フライヤー・結果画面（HTMLを重ねて表示）
- `src/save.js` … 日数・所持金・在庫・発注を localStorage に保存（失敗しても遊べる）

セーブは「翌日へ」を押したときに、翌日の開始時点の状態で保存します。途中で再読み込みした場合は、その日の開店前からやり直しになります。
